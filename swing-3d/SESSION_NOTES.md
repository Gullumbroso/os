# סיכום השיחה – The Swing FPV (Seedance)

## המטרה
להפוך את הציור *The Swing* (פרגונאר, 1767) לסדרת סרטונים: מצלמה מרחפת באיטיות *לתוך* הציור, כאילו הוא סצנה תלת־ממדית. **הזמן קפוא**, רק המצלמה זזה. למשל: המצלמה נכנסת ומסתובבת לאט סביב הנעל שעפה.

## מה נעשה עד עכשיו
- **ה-PDF (BRINGING PAINTINGS TO LIFE):** נלמדה ממנו השיטה. מציירים על התמונה קו אדום עם Point 1 ו-Point 2, ונותנים ל-Seedance פרומפט קבוע שמורה לו לעקוב אחרי המסלול ולמחוק את הסימונים.
- **4 נקודות עניין** (את הנעל בחר המשתמש, את השאר בחר Claude):
  1. הנעל שעפה באוויר
  2. האישה בנדנדה (פנים, כובע, שמלה)
  3. המאהב בשיחים עם הכובע
  4. פסל הקופידון עם האצבע על השפתיים
- **8 תקריבים** שנוצרו עם `gpt-image-2` דרך ה-API של OpenAI. שני תקריבים לכל נקודה: אחד מקרוב, ואחד מזווית אחרת או מסלול הקפה. כל תקריב קיבל כרפרנס חיתוך מהציור + הציור המלא. התיקייה: `closeups/`.
- **4 תמונות מסלול** עם קווים אדומים, אחת לכל קטע. התיקייה: `paths/`.
- **פרומפטים ל-Seedance** לכל קטע, וטבלה שמפרטת מה מעלים בכל קטע: `README.md`.
- **הסקריפט ליצירת התקריבים מחדש:** `gen_closeups.py`. הוא משתמש ב-streaming, כי הפרוקסי בענן מנתק בקשות אחרי כ-30 שניות.

## 4 הקטעים
| # | תנועה |
|---|---|
| 1 | כניסה מהשיחים, עלייה אל הנעל, הקפה איטית סביבה |
| 2 | מהנעל, מתחת לרגל ולאורך השמלה, עד תקריב של פני האישה |
| 3 | ירידה מתחת לנדנדה, צלילה לשיחים, עצירה מאחורי כתף המאהב |
| 4 | עלייה אל פסל הקופידון, הקפה מאחוריו, מבט על כל הסצנה הקפואה |

כל קטע מתחיל איפה שהקודם נגמר. כדאי להשתמש בפריים האחרון של כל קטע כפריים הפותח של הקטע הבא.

## החלטות ומה שנשאר פתוח
- **מודל הווידאו:** הוחלט להשתמש ב-**Seedance** (לא Sora, לא Higgsfield).
- **הרילס באינסטגרם** (https://www.instagram.com/reel/DbnPNMGixDE/) לא נצפה, כי הסביבה בענן חוסמת את אינסטגרם. כדי לפתור: להעלות את הסרטון כקובץ, או לאשר את `instagram.com` ואת `cdninstagram.com` ב-Network access של הסביבה.
- **הרצת Seedance דרך קומפי.** ל-Seedance בקומפי יש API node שעובר דרך `api.comfy.org`. שתי אפשרויות:
  - **בענן:** ליצור API key ב-platform.comfy.org, לשמור אותו בהגדרות הסביבה כ-`COMFY_API_KEY`, ולהוסיף את `api.comfy.org` ואת `platform.comfy.org` ל-Allowed domains. אחרי זה פותחים סשן חדש.
  - **מקומית:** להריץ את Claude Code על המחשב, עם גישה ל-`localhost:8188`.
  - או ידנית דרך הווב, לפי הטבלה ב-`README.md`.
